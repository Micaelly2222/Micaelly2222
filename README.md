## About me

I like working with data and AI applied to real problems. Day to day, I develop applications with **LLMs and RAG**, build data pipelines on **Databricks and Airflow**, and train **Machine Learning** models. I have also developed **APIs in Python**, automated data collection with **web scraping**, and built **ETL pipelines**.

## What I do

- 🤖 **Generative AI:** LLM applications, RAG, embeddings, semantic search and AI agents with function/tool calling, using validation, fallback and human review so answers can be trusted in production.
- 🧱 **Data engineering:** pipelines with Python, PySpark and SQL on Databricks, orchestrated with Airflow (retries, monitoring, data quality tests).
- 🔌 **Backend:** REST APIs in Flask and FastAPI with JWT/OAuth2, Docker and CI/CD.
- 📊 **Machine Learning:** classification, scoring, recommendation and time series.

## Core skills
